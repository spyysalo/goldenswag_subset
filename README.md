# GoldenSwag subset

Special-purpose script to select the [GoldenSwag](https://arxiv.org/abs/2504.07825) subset of a [HellaSwag](https://arxiv.org/abs/1905.07830) dataset.

Example usage:

```
python3 goldenswag_subset.py LumiOpen/opengpt-x_hellaswagx FI PleIAs/GoldenSwag spyysalo/GoldenSwag-ogx-FI
```

Resulting dataset: https://huggingface.co/datasets/spyysalo/GoldenSwag-ogx-FI
